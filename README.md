## What I build

### Horizon Gateway

> 로컬 개발 인프라를 관측하고 제어하는 Agentic DX 데스크톱 앱

- 도메인 헬스체크, HTTPS MITM 프록시, API 모킹, 모바일 터널링
- Cursor·Claude·Gemini 등이 기능을 인지하고 제어할 수 있는 CLI 및 Agent Skill
- Tauri 2 + Rust 기반의 경량 크로스플랫폼 앱
- 실제 팀 개발 환경에 도입하여 프로덕션 도메인의 로컬 검증에 활용

**Stack:** Rust · Tauri · React · TypeScript  
**Links:** [Product](https://gateway.delete-horizon.com) · [Repository](https://github.com/GrangbelrLurain/horizon-gateway)

### ViewKit

> 기기와 설치 환경에 덜 종속되는 서버리스 MFA(Multi-Frontend App) PWA 메쉬

- 서로 다른 도메인의 PWA를 공통 embed protocol로 연결
- Turborepo 기반 travel·hotel·shell·auth·catalog 앱 구성
- IndexedDB와 정적 배포를 활용한 local-first·serverless 구조
- 모바일·데스크톱에서 이어지는 여행 일정 및 카탈로그 경험

**Stack:** React · TypeScript · Turborepo · PWA · Cloudflare Pages  
**Live:** [Travel Planner](https://travel.delete-horizon.com/?mode=edit) · [Hotel Catalog](https://hotel.delete-horizon.com/)
